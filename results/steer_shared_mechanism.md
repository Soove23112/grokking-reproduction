# Restricted and excluded loss after the projection (shared starting state)

Restricted loss: only the constant and cos/sin(w_k(a+b)) of the frequency set kept in the logits, all pairs. Excluded loss: those terms removed, training pairs. 'proj': the projected set (for `none`, the top-4 set of the same initialisation); 'final': the key frequencies of the run's final weights. Chance level ln 113 = 4.73. Epoch 100 is just after the projection.
